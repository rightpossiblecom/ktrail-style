# KTrail Style — design note

## STYLING LOCK (owner)

**Do not change the styling.**

Keep Frisor’s visual system exactly as cloned:

- Same `globals.css` / Tailwind tokens  
- Same fonts  
- Same dark editorial barbershop look (deep green / charcoal + gold accents)  
- Same component layout language (hero, strips, lookbook, etc.)

**Allowed:** copy, brand strings, CTAs, new routes/pages, dashboard content, config-driven text.  
**Forbidden:** new color themes, font swaps, “make it look like JoashLink,” purple SaaS restyles, redesigning Frisor components for vibes.

If a new Cloud Grant page is needed (`/product`, `/waitlist`, …), **reuse Frisor spacing/type/color patterns** — do not invent a second design system.

## Anti-clone (content, not look)

- Story/copy must be KTrail multi-barber Nigeria + AI preview — not Frisor Berlin single shop  
- Do not paste sibling CloudGrant components  
- Marketing CTAs = waitlist / demo only
